Como usar a Roda ColorADD + CDU

🌈

Bem-vinda!

Esta é a Roda ColorADD + CDU, uma ferramenta inclusiva para etiquetar documentos numa biblioteca usando símbolos universais que qualquer pessoa pode reconhecer — incluindo quem tem daltonismo ou baixa visão.

Em poucos passos vais saber tudo o que precisas. Carrega Próximo para começar.

🧭

Os 4 separadores

No topo da app encontras quatro secções:

  • 🎨 ColorADD — escolhe uma cor e gera uma etiqueta simples.
  • 📚 Classes CDU — vê as classes da Classificação Decimal Universal e a cor sugerida para cada uma.
  • 🔗 Combinar — junta cor + classe + título numa única etiqueta para colar na lombada.
  • ✉️ Contacto — envia dúvidas, reporta problemas ou faz sugestões.
🔈

Acessibilidade no centro

Toda a app é pensada para ser acessível:

  • Ouvir página (botão no topo) — lê todo o conteúdo em voz alta, em pt-PT.
  • Ouvir esta secção — botão em cada separador para ler só essa parte.
  • Acessibilidade ⚙ — abre o painel com tamanho de texto, fonte para dislexia, alto contraste, movimento reduzido e modo calmo.
  • Sons multissensoriais — cada cor tem uma frequência musical (ativa em ⚙).
👁️

Simulador de daltonismo

No separador 🎨 ColorADD, em cima, podes simular como cada tipo de visão cromática vê a interface — protanopia, deuteranopia, tritanopia, monocromacia, entre outros.

É excelente para testar etiquetas antes de imprimir e perceberes que o sistema continua legível para todos.

📱

Funciona offline

Esta app pode ser instalada no teu dispositivo e usada sem internet:

  • Telemóvel: menu do browser → "Adicionar ao ecrã inicial" / "Adicionar ao ecrã principal".
  • Computador: ícone de instalação na barra de endereço, ou botão ⬇ Instalar app no topo (se aparecer).

Tens dúvidas? Carrega no botão verde 💬 no canto inferior direito para abrir o assistente.
